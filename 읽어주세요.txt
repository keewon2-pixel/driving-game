[실행 방법]
1. index.html 을 더블클릭하면 게임 선택 화면이 열립니다. 서울 드라이브 / 고속도로 운전 중 고르세요.
2. 서울에서 도로 위 별 3개를 모두 먹은 뒤 동쪽 끝 톨게이트로 들어가면 고속도로 게임으로 자동 이동합니다.
3. 로그인, 설치 없이 실행됩니다. 인터넷 연결만 필요합니다 (3D 라이브러리를 인터넷에서 불러옵니다).
4. 폴더 구조(index.html, 서울드라이브, 고속도로운전)를 그대로 유지해야 합니다.

[PC 조작]
↑↓←→ 또는 WASD : 가속 / 감속(후진) / 조향     Space : 브레이크
X : 필살기 부스터 (10초 초고속, 20초 재충전)     Shift : 달리기 (걸어다닐 때)
F 또는 Ctrl : 총 발사 (차·동물·사람 피격, 차는 여러 발 맞으면 폭발)
Enter : 차에서 내리기 / 가까운 차에 타기 (다른 차를 빼앗아 탈 수 있음)
B : 차량 선택(경찰차·소방차·스포티지·그랜저·택시·오토바이·자전거)
C : 카메라 전환   R : 위치 초기화   M : 소리   P : 일시정지   T : 조이스틱 숨기기/표시

[모바일]
오른쪽 아래 조이스틱(위: 가속, 아래: 감속, 좌우: 조향)과
왼쪽 아래 버튼(브레이크·총·차량·카메라·부스터·타기내리기·후진·초기화)으로 조작합니다.
